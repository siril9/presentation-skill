# v0.12.0 - Readable variety, smaller iterations

The source-first workflow stays the same: describe the deck, build an editable
PowerPoint, inspect it, and repair the source.

- Evidence, decisions, timelines, charts, and source registers fit real text
  more reliably. Dark-cover footers and chart colors have better contrast;
  comparisons reserve space for their verdict instead of covering option text.
- Optional intake asks only for consequential missing context. Saved answers
  influence routing. A low-usage model choice is offered only from caller-supplied
  usage and available-model information; the skill never switches models itself.
- Compact briefs support GPT-6 Sol and Luna alongside existing profiles. One
  capable model can own the whole deck. Optional style auditions compare the
  same content before committing to a design.
- Repair packets identify affected slides and source locations. Verified render
  caching avoids repeat conversions while rebuilding the PowerPoint and rerunning
  checks. Visual approval is never cached.
- Source-fidelity guidance now explicitly checks values, denominators, units,
  caveats, and citations. The controlled gallery also checks retained native text
  and chart data, not just slide geometry.

Examples use one synthetic topic across eight styles, with three clean contact
sheets and editable decks. A separate eight-slide GPT-6 Luna example includes
the source corrections required during review; it is not an unattended-accuracy
or cross-model superiority claim.

The GitHub skill and Codex plugin ship the same runtime. MIT licensing is unchanged.
